# Creative Engine Qwen

Открытая платформа для создания игр, 3D-миров, интерьеров, городов и планет без написания кода.

## 🎯 Цель

Создать интуитивный инструмент, где подросток или новичок сможет:
- Создать небольшую игру
- Собрать 3D-сцену
- Сделать мебель или здание
- Настроить ландшафт
- Использовать визуальную логику
- Экспортировать проект в Web

## 🚀 Возможности

- Браузерный редактор
- Сворачиваемые панели
- 3D/2D viewport с Babylon.js
- Визуальные скрипты (скоро)
- Редактор ландшафта (скоро)
- Shader Graph (скоро)
- Импорт glTF/GLB (скоро)
- Экспорт Web (скоро)

## 🛠 Технологии

- TypeScript
- React
- Vite
- Babylon.js
- pnpm
- Turborepo
