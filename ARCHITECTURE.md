# Architecture

## Структура проекта
creative-engine-qwen/
├── apps/
│ └── web-editor/ # Главный веб-редактор
├── packages/ # Общие библиотеки (позже)
├── docs/ # Документация
├── package.json
├── pnpm-workspace.yaml
└── turbo.json

## Компоненты редактора

- **Editor** - главный контейнер
- **Toolbar** - верхняя панель инструментов
- **SceneHierarchy** - список объектов сцены (левая панель)
- **Inspector** - свойства выбранного объекта (правая панель)
- **Viewport** - 3D viewport с Babylon.js

## Технологии

- **React** - UI фреймворк
- **TypeScript** - типизация
- **Vite** - сборщик
- **Babylon.js** - 3D движок
- **pnpm** - менеджер пакетов
- **Turborepo** - монорепозиторий

## Принципы

1. Модульность - каждый компонент независим
2. Простота - минимум сложных настроек
3. Производительность - быстрая работа
4. Доступность - работает на разных устройствах
